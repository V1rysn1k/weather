Описание модулей
----------------

api
~~~
Модуль для работы с внешними API погоды и геокодирования. Содержит класс 
:class:`api.WeatherAPI` для взаимодействия с Open-Meteo API и Nominatim.

**Основные функции:**
* Геокодирование - получение координат по названию города
* Обратное геокодирование - получение города по координатам
* Получение текущей погоды по координатам

cache
~~~~~
Модуль для работы с кэшем погодных данных в PostgreSQL. Предоставляет функции 
для сохранения и получения данных о погоде из базы данных.

**Основные функции:**
* Кэширование результатов запросов
* Уменьшение количества обращений к внешнему API
* Хранение истории запросов

commands
~~~~~~~~
Модуль команд для получения погодных данных. Содержит функции для получения 
данных о погоде по названию города или координатам.

**Основные функции:**
* Обработка запросов по городу с геокодированием
* Обработка запросов по координатам с обратным геокодированием
* Интеграция с системой кэширования

main
~~~~
Основной модуль приложения. Содержит главную логику приложения для 
взаимодействия с пользователем и обработки вводимых данных.

**Основные функции:**
* Интерактивный интерфейс командной строки
* Автоматическое определение типа ввода (город/координаты)
* Обработка пользовательских команд
