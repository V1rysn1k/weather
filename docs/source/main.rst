Функции модуля
--------------

.. autofunction:: main.is_coordinates

   Проверяет, является ли пользовательский ввод координатами.
   
   **Аргументы:**
   
   * **items** (list) - Список строк для проверки
   
   **Возвращает:**
   
   * bool - True если ввод является координатами, иначе False
   
   **Логика проверки:**
   
   1. Проверяет, что введено ровно 2 элемента
   2. Проверяет, что оба элемента можно преобразовать в float
   
   **Примеры:**
   
   .. code-block:: python
   
      is_coordinates(["55.7558", "37.6173"])  # True
      is_coordinates(["Москва"])              # False
      is_coordinates(["55.7558"])             # False

.. autofunction:: main.process_query

   Обрабатывает пользовательский запрос и определяет его тип.
   
   **Аргументы:**
   
   * **query** (str) - Пользовательский ввод
   
   **Возвращает:**
   
   * tuple or None - Результат запроса погоды или None при ошибке
   
   **Логика работы:**
   
   1. Разбивает ввод на части
   2. Определяет тип запроса (координаты или город)
   3. Вызывает соответствующую функцию из :mod:`commands`
   4. Возвращает результат

.. autofunction:: main.main

   Главная функция приложения. Запускает интерактивный цикл.
   
   **Логика работы:**
   
   1. Выводит приветственное сообщение
   2. Запускает бесконечный цикл ввода
   3. Обрабатывает команды выхода
   4. Для каждого запроса вызывает :func:`main.process_query`
   5. Выводит результат или сообщение об ошибке

Пример работы приложения
------------------------

.. code-block:: text

   Запущено приложение погоды.
   Введите город либо координаты (широта и долгота). Для выхода введите 'exit' или пустую строку.
   
   > Москва
   Город: Москва
   Координаты: широта 55.7558, долгота 37.6173
   Температура: 15.5 °C
   
   > 59.9343 30.3351
   Город: Санкт-Петербург
   Координаты: широта 59.9343, долгота 30.3351
   Температура: 12.3 °C
   
   > Лондон
   Город: Лондон
   Координаты: широта 51.5074, долгота -0.1278
   Температура: 8.7 °C
   
   > exit
   Выход из программы.

Команды выхода
--------------

Приложение поддерживает следующие команды для выхода:

* ``exit``
* ``выход`` 
* Пустая строка

Обработка ошибок
----------------

Приложение обрабатывает следующие типы ошибок:

* **Некорректный ввод** - выводит сообщение об ошибке
* **Город не найден** - сообщает о невозможности найти город
* **Ошибки API** - выводит сообщение о проблемах с получением данных
* **Ошибки базы данных** - выводит сообщение о проблемах с кэшем
